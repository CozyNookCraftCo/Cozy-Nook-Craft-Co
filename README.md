# Cozy Nook Craft Co. website

The live site at cozynookcraftco.com is published from the **`site`** folder only.

- Edit the pages in `site/` (`index.html`, `story-shop.html`, `preference-sheet.html`).
- Netlify publishes `site/` automatically whenever `main` changes.
- Files outside `site/` (zips, older page copies, the "COZY NOOK USE ME ALWAYS" folder) are backups. They are never published.
